Compile from this directory with a standard LaTeX installation:

pdflatex manuscript_revised_red.tex
pdflatex manuscript_revised_red.tex
pdflatex supplementary_revised_red.tex
pdflatex supplementary_revised_red.tex

Alternatively, compile each source with Tectonic. References are embedded in
each source; no BibTeX step or separate bibliography file is required. Keep the
figure and supplementary_data directories beside the sources. The CAS class,
style and email-icon asset are necessary dependencies. The separately supplied
PDFs were compiled with Tectonic 0.17.0. Analysis code and processed cell inputs
are supplied in the separate reproducibility archive.
