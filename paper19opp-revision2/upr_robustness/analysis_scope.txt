UPR response-ordering robustness extension

This extension is based only on the current manuscript and its frozen gene cohorts,
source rankings, and original public count matrices. The manuscript framework,
title, Introduction, non-UPR analyses and unrelated statements are outside scope.
The current manuscript and response hashes are in current_manuscript_baseline.json.

Evidence status
All K562, Adamson, Frangieh and RPE1 contexts have previously been examined for
Hallmark-UPR effects. Newly defined signatures, metrics and statistical families
are locked before their corresponding calculations, but these analyses are
specification-limited robustness and biological annotation analyses, not a new
untouched independent validation. Existing independent-study identities remain
as stated; RPE1 is a same-study cellular-context holdout. No treatment threshold,
module membership, source score or validation cohort may be selected from new
results. No replacement list is allowed when literal Top10/20 members lack support.

Questions fixed before additional outcome summaries
1. Source-signed-UPR quintiles over the existing438 genes: mean/median/signed
   response, Q5−Q1, ordered trend, slope, all adjacent changes and uncertainty.
   A positive overall trend alone is not proof that every adjacent change is
   positive. Preserve source-defined groups and complete gene observations.
2. Four authoritative functional expression readouts: ER folding, ERAD quality
   control, ER targeting/import and integrated stress response. Official GO IDs,
   exact memberships, relations, identifier mapping, release records and source
   downloads are fixed by metadata before response calculation. Readout expression
   does not establish biochemical module activity. Target-function strata are
   separately descriptive, retaining small/absent groups.
3. Independent UPR definitions: Reactome R-HSA-381119 primary, GO:0030968
   sensitivity, full and Hallmark-disjoint membership; between-functional-module
   unique memberships are fixed sensitivity signatures. No failed set is replaced.
   Existing6780 genes define the common normalization library. Missing features
   remain unavailable, not observed zeros. Report full/retained/intersection sizes.
4. Candidate utility: literal frozenTop10/20 and all pre-existing source-only
   comparator rankings. Precision@K uses validationeffect>0; NDCG uses max(effect,0)
   with linear gain and log2 rank discount, without optimized validation cutoffs.
   Compare source-positiveUPR alone, baselineexpression, sourcecellcount,
   genericresponsemagnitude, DepMapessentiality, uniformrandom rankings and the
   same frozen100expression/detection-matched randommodule rankings.

Bias and uncertainty controls
Real signatures are rescored with exact own-target numerator and denominator
exclusion in treated and control cells. Real-vs-randommodule calibration uses a
separate matched fixed6780-library assay with identical own-member numerator
exclusion in real and null signatures; never compare differing normalizations.
Source-control expression/detection define random module matching before module
response outcomes. Newrealreadout source-only ranks may be computed only after
membership/covariates are frozen and before corresponding validation scoring;
label all such alternate-definition rankings as sensitivity, and keep current
Top10/20 unchanged. Original whole-gene panels and incomplete covariate flags remain.

Gene interventions, not individual cells, form primary correlation/ranking units.
Joint gene resampling preserves repeated-context and ranking-overlap dependence.
Technical GEM wild sensitivities share weights across genes/methods; matched-control
and scaling assumptions are explicit. Cell-depth subsampling is a sensitivity
range, not biological replication. Control for sourcecontrol expression/detection,
source/validation counts, library depth and generic RNAresponse using fixed minimal
covariates, with incomplete/collinear cases reported. Sign-concordance nulls preserve
both sign marginals. Different significance labels do not establish context differences.

Multiplicity
The ranking/quintile family and module/independent-definition families are enumerated
in their locked protocols before computations. RawP, family IDs, all results and
unestimable signatures are retained. Primary conclusions use the complete declared
family correction; within-subfamily values cannot rescue failure in the complete
family. An additional globalBH sensitivity pools all newly declared primary
hypothesis tests across components. Descriptive intervals/nullpercentiles are
explicitly distinguished from confirmatory hypothesis tests.

Scientific and reporting rules
Retain every negative result. Stronger direction precision is not stronger absolute
response or functional benefit. Correlation is not calibrated response prediction.
No algorithmic or pathway-specific advantage is claimed unless matched simple and
random controls support it. If specificity or utility fails, narrow only the directly
related UPR claims. Preserve actual run commands, stdout/stderr, softwareversions,
seeds, hashlocks, source downloads, numerical outputs, figure source tables and a
sentence-level manuscript change record separately from the minimal submission ZIP.
