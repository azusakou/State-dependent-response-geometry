SPECIFICATION-LIMITED UPR DEFINITION AND FUNCTIONAL-READOUT ROBUSTNESS
2026-11-06. Statistical seed 2026110611.

Scope and timing
The original Hallmark UPR outcomes, candidate tests and RPE1 results have already
been examined. This extension is written before calculating the new curated-set
response associations. Fixing new memberships before their summaries does not
restore an unused validation set. All outputs are specification-limited robustness
analyses of previously used datasets, not new independent validation, prospective
experiments, or retrospective preregistration of the original study. No successful
definition, threshold, direction, cohort or ranking replaces a failed one.

Authoritative measurement definitions
The independent extraction owner fixes human memberships from authoritative GO
and Reactome resources, their versions/URLs, the shared measured-gene universe,
overlap/coverage and hashes before response summaries. The four functional RNA
readouts are GO:0034975 (ER protein folding), GO:0036503 (ERAD), GO:0045047
(protein targeting to ER, including co/post-translational targeting/import;
not ER-to-Golgi vesicle traffic), and GO:0140467 (integrated stress response
signaling, including the kinase branches). They are positive-member expression
summaries; their names do not establish activation, flux or a signaling mechanism.

Independent UPR definitions are Reactome R-HSA-381119 and GO:0030968, each full
and after subtracting the measured Hallmark-UPR members. These give four
definition-robustness axes in addition to the four functional axes. The GO parent
may be unavailable; unavailable definitions stay in all fixed inferential families
as unestimable. Full and Hallmark-disjoint variants are paired specifications,
not independent biological observations. No handpicked replacement genes enter.

Scores use the same metadata-intersected measured-gene universe across Replogle
K562/RPE1, Adamson and Frangieh. Duplicate raw symbols are summed before log.
Every score is a mean log(1+10000*count/library) over measured members, with the
perturbed gene removed from the numerator when applicable and from the library
denominator when measured. Treated and matched-control cells receive the same
gene-specific correction. Matched-GEM means and the applicable global control SD
are recomputed exactly from raw terms. A score is mathematically estimable only
with at least one remaining member and finite positive control SD. Few-member
definitions are retained and flagged; fewer than three measured members cannot
establish a distributed program. Empty/zero-variance scores are NA, never zero.
No minimum set-size search, imputation of absent genes or response-based QC occurs.

Fixed target panels and effects
Keep the existing 438 K562/RPE1 targets, 30 Adamson targets, 19 untreated Frangieh
targets, 19 IFNg targets and 17 co-culture targets. Report the fixed target panel
and the number of mathematically estimable pairs for every axis/context. Source
effects for those targets use the same remeasured assay basis. No new eligibility
gate, positive-effect restriction or gene-significance filter is introduced.
Per-gene effects are target-cell-weighted matched-GEM treated-minus-control mean
contrasts divided by the relevant target-specific global NTC SD. All per-gene,
GEM, target/control support, measured-member and control-expression outputs remain.

Primary robustness family: forty rank associations
For each of eight axes in each of five comparisons, compute signed source versus
external Spearman rho over every estimable target. A correlation requires at least
three pairs and nonconstant vectors; otherwise it is unestimable. Use 4,999
whole-gene bootstrap draws, retaining every vector element/context for a sampled
gene. The 2.5th/97.5th percentiles form conditional intervals; report valid-draw
counts, and mark an interval NA when fewer than 1,000 draws are finite. Permute
external gene labels with 19,999 shared draws, using the same permutation indices
across axes in a context when estimable panels agree. Two-sided Monte Carlo tails
are centered on the permutation mean, with tolerance1e-12 and +1 correction.
Apply BH jointly across all forty prespecified axis/context hypotheses. Unavailable
tests receive P=1 for correction while retaining estimate/P fields as NA. Never
recompute a smaller favorable family. Report all40, including inverse/null results.

Direction and signed-effect consistency: eighty secondary tests
For each axis/context, report source/external positive, negative and zero counts,
and concordance mean(I(source_effect*external_effect>0)) over the estimable panel.
Zero effects are not positive concordance. The permutation reference preserves
each context's marginal sign composition; no unsupported 50% chance assumption
is used. Also report C=mean(sign(source_effect)*external_effect), the source-sign-
aligned external standardized shift. C is a conditional signed-effect consistency
summary, not calibrated cross-context amplitude or a selected-candidate endpoint.
Use the same whole-gene bootstrap and gene permutations as for rho. Center two-sided
tails on the permutation mean, because globally shifted contexts need not have a
zero direction/consistency null. BH correction covers all40 direction plus40 C
tests jointly (80 hypotheses). No direction or effect-size threshold is tuned.

Study-balanced meta-summary and stability
For each axis, average the three Frangieh C estimates equally, then average this
study-family summary, Adamson C and RPE1 C equally. All three source families and
all three Frangieh conditions are required; otherwise this meta-summary is NA.
This is an explicitly study-balanced descriptive signed-response summary, not an
independent-study inverse-variance meta-analysis or a common-effect estimate.
For its conditional interval, sample genes from the union with replacement,
carrying all available contexts and missingness patterns together; recompute the
fixed hierarchy in each draw. No missing response is inserted as zero. Report
4,999-draw interval and leave-one-study-family-out range, without a new significance
test. Also report leave-one-target-out rho/C ranges and paired full-versus-disjoint
differences on identical targets. These are influence/specification diagnostics.

Fixed minimal generic-response controls
Use four separate rank-residual sensitivity models for each of the forty pairs:
(a) log source and external target-cell counts; (b) source and external NTC target
expression; (c) source and external Euclidean norms of the same three short-module
effects; (d) source and external E2F effects. The short modules/E2F are recomputed
on the same universe with the same own-target corrections. No model combines all
covariates. Retain exact complete-case counts and report missingness; no imputation.
Partial Spearman is correlation of OLS residuals from ranked response/covariates.
Require residual rank and at least three residual degrees of freedom; otherwise
NA. Whole-gene bootstrap repeats residual fitting. A Freedman-Lane sensitivity
permutes the external-response residual after conditioning on the fixed covariates,
refits and recomputes the partial correlation with 19,999 draws; BH covers all160
axis/context/control-model tests. These controls are conditional diagnostics, not
causal adjustment or evidence that a pathway is independent of global biology.

Readout-specific negative controls, if technically available
Before response association summaries, the extraction owner may freeze100 random
modules for each exact measured readout size, matched using source NTC mean
expression/detection five-by-five bins and the existing deterministic nearest-bin
expansion scheme. The tested module and Hallmark-UPR genes are excluded; no
validation value defines a pool or bin. Freeze modules/seed/coverage and keep every
failed module; do not substitute the previous90-gene nulls for a differently sized
definition. Null scores receive identical own-target numerator/denominator and
control-SD correction. For every axis/context compare observed rho and C with all
estimable random-module values, using (1+number(null>=observed))/(1+finite nulls).
Report finite-control upper-tail fractions and null coverage/distributions; these
are specification calibrations, not biological replicates or permutation P values.
No new corrected significance is claimed from these optional finite-null summaries.
If unavailable, mark readout-specific specificity unresolved rather than using an
unmatched background. Negative controls may challenge, but never tune, the axis.

Cell support and ranking projections
Use200 without-replacement draws of100 target cells in each context for438 genes,
and30/15 target cells for the fixed smaller external panels where support permits.
Original matched-GEM control means and gene-specific SDs stay fixed. No target list
is shortened/refilled; report retained target counts when a depth is unestimable.
These are depth-perturbation ranges, not gene-confidence intervals. Existing source
UPR quintiles, Top10/20 priorities and comparators remain fixed if projected onto
the new definitions. No alternate-definition source ranking is made in this task;
any such ranking requires a separately frozen plan. Generic magnitude, expression,
count and essentiality comparisons use identical available target populations.

Reproducibility and claim boundaries
Save this text/hash before metrics, append authoritative definition/input hashes
without changing choices, and preserve executable R code, actual stdout/stderr,
session information, seeds, complete result tables and plot data in this directory.
Any coding repair is logged with the original file retained; no choice may be
altered because a result is negative. Summaries distinguish source-study/context
and measurement definitions. Support means transport of a specified transcriptional
readout; it does not identify canonical pathway activation, unique UPR conservation,
functional benefit, general cell-state control or a new independent experiment.
