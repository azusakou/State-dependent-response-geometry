ALTERNATIVE UPR-DEFINITION RANKING SENSITIVITY
2026-11-06; seed2026110608. This extension is fixed before release of the newly scored alternative-definition validation effects. Original RPE1 outcomes have already been evaluated. It is retrospective sensitivity analysis, not a new independent validation or a replacement for the current source ranking, cohort or principal findings.

Definitions and modes
The four externally defined parent axes are Reactome_UPR_full, Reactome_UPR_no_Hallmark, GO_ER_UPR_full and GO_ER_UPR_no_Hallmark. Their authoritative metadata-frozen memberships, universe, own-target treatment, raw-scoring/reference checks and checksums are supplied by the separate scoring workflow. Primary normalization for these parents is exact_Lminus_target; fixed_L6780 is a separately labeled sensitivity. Neither the parent definition nor mode may be selected by its validation result. In each mode both source and validation readouts must follow the same normalization contract. The current438-gene and common-covariate370-gene rosters remain fixed. No new response, significance, direction or agreement eligibility gate is introduced.

Source-only rank lock before validation effects
Receive K562 source gene and GEM effect tables only, leaving the newly scored RPE1 parent effects unopened. For every definition and mode, use the supplied target-cell-weighted standardized source effect d_g and the fraction f_g of supported source GEMs with a positive contrast, with support fixed at at least five target cells per GEM. The score is S_g=max(d_g,0)*f_g. Sort by descending S_g, then descending signed d_g, then ascending gene symbol. Define Top10/20 on438 and on the existing370 roster, with no validation-fitted weight or K. Also freeze a corresponding simple raw-source ranking by descending max(d_g,0), then signed d_g and gene symbol. Source undefined scores remain missing and their coverage is reported, never imputed as a negative value; any undefined required literal list is not estimable.
Freeze hashes of the source-only tables, all resulting orderings/Top10/20 lists, mode/definition metadata, and any newly needed source-only matches before releasing corresponding RPE1 effects. Retain original current-Hallmark priority, raw-UPR, expression, essentiality, generic three-module magnitude, count and tie-limited annotation lists verbatim. Source-only rank stability versus the CURRENT priority ranking is summarized by Spearman/Kendall rank association, Top10/20 overlap counts and Jaccard index. These source-stability calculations contain no validation effects.

Evaluation after source lock
On each corresponding RPE1 parent readout, evaluate BOTH the current fixed lists and the newly source-frozen definition lists, together with their new raw-source baseline and all original simple comparator lists. Do not rerank a list using RPE1 values. Precision@10/20 remains fraction signed RPE1 d>0; NDCG@10/20 uses untransformed linear gain max(d,0), log2 discounts, and same-cohort validation-ideal DCG only as a descriptive normalizer. Signed/absolute mean effects, positive-sign enrichment, cohort prevalence, sign concordance, coverage and overlap remain contextual descriptive summaries. Comparable named-method results use the same370-gene roster;438-gene results are labeled separately. All literal TopK members must remain present, with no silent truncation or refill.
Where new matched-background lists are needed, freeze them from SOURCE covariates only using the original four covariates and deterministic equal-weight Euclidean greedy matching: log source count, control expression, generic three-module magnitude and DepMap essentiality; five distinct backgrounds per selected role, no background replacement across Top20, Top10 using its nested role subset. Complete matches are required; unavailable full438 matched lists are retained as unavailable. Existing current-list matches remain unchanged.
Use2,000 paired whole-gene bootstrap multiplicities shared across all lists/readouts within a cohort. Fixed-list Precision uses weighted denominators; NDCG differences use the same conditional observed-IDCG convention as the locked main ranking extension. If corresponding per-GEM effects or shared-GEM draws are supplied, add the same conditional shared-GEM Rademacher sensitivity, keeping source ranks fixed and recomputing signs, gains and IDCG. Report exact/fixed modes separately and do not pool intervals as independent biological replication. All comparisons in this extension are sensitivity estimates with conditional intervals; no new formal P-value family or rescue significance test is added. The separate axis-correlation family is handled in its own analysis.
