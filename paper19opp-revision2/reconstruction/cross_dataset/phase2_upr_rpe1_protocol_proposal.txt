Phase 2: source-fixed UPR prioritization in an unexamined RPE1 context
STATUS: PROPOSAL. No RPE1 expression outcome has been scored or inspected by this analysis. This file is not a frozen protocol or a public preregistration.

Reason for this phase
The initial aggregate priority did not beat simple magnitude. A subsequent, multiplicity-corrected 48-comparison exploration identified ordinal UPR response conservation in Adamson and Frangieh Control. That exploration does not establish amplitude transfer, direction agreement, immune-context specificity or superiority over generic response/essentiality. Frangieh equal-cell and single-guide checks are uncertain. Phase 2 tests a narrower hypothesis in a distinct RPE1 cell context from the same Replogle study. It must not be presented as an independent published-study replication or as validation of a baseline-state principle.

Execution gate
Root must approve the concrete plan after the own-target-excluded Adamson and Frangieh Control associations remain positive. Until then, do not score RPE1 expression, finalize a source ranking, or create a completed lock record. Outcome-blind preparation of code and review of RPE1 measurement/count metadata are permitted. All subsequent deviations must be documented and cannot be chosen using RPE1 outcomes.

Fixed measurement amendment
Use the 6,780 symbols measured in both the existing 7,848-gene discovery universe and RPE1. Sum duplicated symbols before transformation; RPE1 has duplicated HSPA14. Use this same 6,780-gene count sum in K562 and RPE1 CP10k. The UPR readout is the fixed 90 measured members of the prior 91-member Hallmark set, with unmeasured NFYA removed from BOTH contexts. This amendment is based only on measurement metadata. All completed five-study analyses retain their original 7,848-gene/91-member definition and are not silently rewritten.

Primary own-target exclusion
For each assayed gene g, remove g from the UPR numerator if it is a UPR member in both contexts, including the corresponding control mean and control variance. Do not simply remove a term from a standardized aggregate effect. The primary library denominator remains the fixed 6,780-gene sum. Cache target counts and membership flags for an explicitly declared composition sensitivity in which the denominator also excludes g, but ONLY if g contributed to that normalization universe. An assayed gene outside the universe must not be subtracted from its library sum. The numerator and denominator exclusions address different artifacts.

Source and validation rosters
The K562 roster and its existing QC mask remain unchanged. Source genes require at least 100 QC-retained cells and at least three GEM partitions each containing at least five target cells. This is a metadata/support rule, not a response-significance or agreement gate. The RPE1 roster is the author-deposited cell object; it has no QC-pass or doublet label. Retain finite positive recorded UMI counts and record unscorable common-library zeros, without fitting a new classifier or using expression responses to change the gene roster. RPE1 genes require at least 100 deposited cells and at least three recorded GEM labels. RPE1 technical GEM labels are not biological replicates. The metadata audit currently identifies 438 shared genes after the source five-cell/GEM requirement; the previous 454 count used the weaker source GEM-count rule. Do not replace the roster with the 390 genes that also have three five-cell RPE1 GEMs; that is a declared support sensitivity, not an outcome-dependent primary gate.

Effects and source score
For gene g and GEM k, the response is the mean target-cell UPR score minus the matching non-targeting-control mean. Pool these GEM contrasts with target-cell-count weights over all represented GEMs. Standardize by the global non-targeting-control SD of the applicable target-excluded UPR score within that context. The source agreement fraction uses only source GEMs with at least five target cells: f_g is the fraction with positive matched-control UPR contrasts. The source score is S_g=max(source UPR deltaZ_g,0)*f_g. No fitted biological weights, validation-trained penalties or outcome-derived cutoffs are allowed. Rank descending by S_g, then source signed UPR deltaZ, then alphabetical symbol for exact ties. Top 10 and Top 20 are nested prefixes of this one fixed ranking. Record how many source-positive eligible genes exist; if fewer than 20 are available, report the support failure without filling the list with a different scoring rule.

Frozen comparators
On the identical shared gene roster, freeze rankings from source raw positive UPR deltaZ, source generic three-program response norm, the already specified DepMap generic essentiality vector, source non-targeting gene expression, and source target-cell count. The three-program baseline uses the same fixed short-module definitions restricted to the phase-2 measured universe; it is a distinct phase-2 baseline and does not redefine earlier results. Every ranking and Top 10/20 list is source-only. RPE1 metadata supplies eligibility; RPE1 expression does not supply score weights, ranks, thresholds or matches. Missing comparator values are not imputed as known negatives: use a common complete-comparator subset for matched comparisons and report coverage.

Matched background proposal
Before RPE1 expression, construct five distinct background genes per Top-20 gene, without replacement across the complete Top-20 match. Match on four source-only covariates: log1p source target-cell count, non-targeting target-gene expression, generic three-program response norm and generic DepMap essentiality. Standardize each covariate using the eligible source roster; use equal-weight Euclidean distance. Process Top-20 genes in frozen score order; resolve distance ties alphabetically. No UPR response is included as a matching variable because it is the signal being prioritized. The Top-10 background is the corresponding subset of the Top-20 matches. Publish matching distances and standardized mean differences. Poor common support must qualify the matched utility result; do not alter the matching metric or select a different matching scheme after RPE1 outcomes.

Three-endpoint confirmatory family
1. All-eligible-gene Spearman correlation between source signed UPR deltaZ and RPE1 signed UPR deltaZ. This directly tests the ordinal conservation hypothesis selected by the exploratory screen. Also report the score S_g correlation as a ranking diagnostic, without substituting it for the signed-effect endpoint.
2. Top-20 mean RPE1 signed UPR deltaZ minus the mean of its frozen matched background.
3. The analogous Top-10 mean gap, declared secondary but included in the same multiplicity family.
Use two-sided tests and Holm correction across these three endpoints. Positive support requires a positive point estimate as well as its adjusted significance; a significant negative effect does not validate the directional prioritization hypothesis. Report all three outcomes, not only a successful cutoff.

Inference proposal
Use 10,000 gene-label permutations for the ordinal association, with fixed strata defined before outcomes from source expression tertile and source count tertile. For the Top-20/10 matched gaps, permute the role of the selected gene within each frozen six-gene matched set; use the same permutation draws for the nested Top-10 and Top-20 endpoints. These are conditional association/utility tests under matched exchangeability, not randomized causal tests. Report 2,000 complete-gene bootstrap intervals and separate technical-GEM and crossed gene/GEM conditional intervals. Shared control pools and shared GEM references must remain intact. Do not count cells, technical partitions or computational draws as independent biological experiments.

Baseline utility assessment
Report Top-20 and Top-10 mean RPE1 UPR responses for every frozen comparator on identical genes, plus paired differences against raw UPR magnitude. The composite score cannot be described as adding prioritization value unless it improves the relevant simple comparison. Treat additional comparator p values as a separately identified exploratory Holm-adjusted family; do not add them to, replace, or select among the three locked confirmatory endpoints. Source-driven prioritization and signed-effect conservation are distinct claims.

UPR-versus-generic-module specificity control
Before RPE1 expression, generate exactly 100 random 90-gene modules from the same 6,780-gene universe, excluding UPR genes. Match each UPR member to source non-targeting mean-expression and detection bins. Use five quantile bins per covariate, fixed seed 20261106. Sample without replacement within each null module. If an exact bin lacks enough genes, expand by increasing Manhattan bin distance with deterministic alphabetical ties; retain the chosen distance and balance audit. These modules are fixed negative controls, not candidates for selecting an alternative positive story. Hash every membership list before RPE1 access.

Compute two complementary null calibrations on the same eligible assayed-gene panel. First compare real UPR signed source/RPE1 rank conservation with the rank-conservation distribution for the matched random modules. Second freeze each random module's source score and Top-20 list using the same positive-deltaZ/agreement formula, then evaluate those lists on the SAME RPE1 UPR outcome used for the real UPR list. Their matched-background construction uses the same fixed source-only variables and algorithm. This distinguishes generic module transport from specifically prioritizing the UPR endpoint. Report all 100 null results, observed percentile positions and finite-null empirical tail fractions; these computational controls do not constitute additional biological replication. If UPR is not distinct from the matched null distributions, retain the empirical association but do not claim pathway-specific prioritization.

Declared sensitivities, all retained
Equal 100-cell resampling in both contexts (200 fixed-seed draws); support sensitivity requiring three RPE1 GEMs with at least five target cells; target-gene-excluded normalization denominator for the real UPR score; source/RPE1 technical-GEM conditional checks; leave-one-gene influence; and descriptive comparison with proliferation/E2F responses. The primary ranking remains frozen. Resampled source rankings, if generated, must be labeled sensitivity rankings and cannot replace the locked primary list. No RPE1 post-treatment proliferation score enters the primary ranking or matching; adjusting for a measured downstream program is a descriptive specificity analysis and can remove biology as well as nuisance variation.

Source cache for exact composition checks
During the source-only block scan, retain the original 91-member UPR raw-count matrix for all QC source cells, original 7,848-gene and phase-2 6,780-gene library sums, assayed-target raw counts, target_in_original_universe and target_in_phase2_universe flags, and matched-control target-count columns for the original fixed Adamson/Frangieh target union. Also retain phase-2 non-targeting expression/detection statistics and exact measured membership. Aggregate duplicate symbols before any library subtraction. This supports exact numerator and denominator exclusions; post-hoc scaling of aggregate log scores is not valid.

Freeze record and interpretation boundary
After root approval and source construction, record UTC time and SHA256 hashes for the source QC roster, phase-2 universe, UPR membership, 100 null memberships, shared eligible genes, source score, comparator ranks, Top-10/20 lists, frozen matches, analysis code and tests BEFORE RPE1 expression is opened. The record documents a newly locked follow-up hypothesis, not preregistration of the original study. RPE1 is a same-study held-out cell context. A positive result supports reproducibility/prioritization of a molecular UPR readout within this design; it does not establish a universal baseline-state effect, functional death, optimal intervention control, a pathway mechanism or a therapeutic benefit.
